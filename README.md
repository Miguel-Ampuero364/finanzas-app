# Finanzas

App web para llevar finanzas personales y del taller en Bs. Funciona como una app instalable en el celular.

Este repositorio contiene **solo el código de la web**. No guarda datos ni claves: la información vive en las hojas de Google de cada persona y se conecta desde la pantalla *Ajustes* con la dirección y la clave de su propio puente.
